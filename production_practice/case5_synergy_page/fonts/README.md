# Synergy Sans

В каталоге находится официальный вариативный шрифт `SynergySans-VF.ttf`, предоставленный в бренд-материалах Университета «Синергия».

Шрифт подключён в `generate_page.py` и готовом `synergy.html` через `@font-face` с диапазоном насыщенности `100 900`. Все ресурсы загружаются локально, поэтому фирменное начертание работает и без доступа к интернету.
