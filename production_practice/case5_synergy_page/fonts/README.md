# Файлы Synergy Sans

Скачайте официальный пакет шрифтов на <https://brandbook.synergy.ru/> и поместите сюда веб-версии шрифта под именами:

- `SynergySans-Regular.woff2`;
- `SynergySans-Bold.woff2`.

Если в официальном архиве имена отличаются, переименуйте соответствующие файлы либо скорректируйте пути в `generate_page.py`. Сами файлы шрифта не включены в учебный репозиторий; при их отсутствии используется резервный шрифт Arial.
