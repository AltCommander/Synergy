# Кейс-задача № 5 — HTML-страница об Университете «Синергия»

`generate_page.py` создаёт автономную адаптивную страницу `synergy.html` с информацией об организации, на базе которой проходила практическая подготовка.

Страница соответствует условию задания:

- содержит требуемый заголовок и сведения об Университете;
- использует официальный локальный шрифт `Synergy Sans`;
- показывает тот же текст ещё в пяти шрифтовых вариантах;
- оформлена по базовой палитре визуальной системы Университета;
- работает без внешних библиотек, CDN и подключения к интернету.

## Запуск

```bash
python generate_page.py
```

После запуска откройте `synergy.html` в любом современном браузере. Готовый HTML уже включён в репозиторий, поэтому запуск генератора требуется только для повторной сборки.

## Структура

- `generate_page.py` — программа-генератор на стандартной библиотеке Python;
- `synergy.html` — готовая HTML-страница;
- `fonts/SynergySans-VF.ttf` — официальный вариативный шрифт Synergy Sans;
- `fonts/README.md` — сведения о подключении шрифта.

Основные цвета взяты из визуальной системы Университета: красный `#ED131C`, чёрный `#000000`, серый `#E0E1E5` и белый `#FFFFFF`.
