# Кейс-задача № 5 — HTML-страница об Университете «Синергия»

Программа `generate_page.py` создаёт автономный файл `synergy.html` с краткой информацией об организации, на базе которой проходила практика.

На странице представлены шесть вариантов оформления текста:

1. фирменный `Synergy Sans`;
2. Arial;
3. Georgia;
4. Trebuchet MS;
5. Verdana;
6. Times New Roman.

## Запуск

```bash
python generate_page.py
```

После запуска откройте `synergy.html` в браузере. Скрипт использует только стандартную библиотеку Python.

## Фирменный шрифт

Официальная бренд-система Университета предлагает пакет `Synergy Sans` на странице <https://brandbook.synergy.ru/>. Инструкция по размещению файлов находится в каталоге [`fonts`](fonts/README.md). Если файлы шрифта отсутствуют, браузер автоматически использует Arial.

Готовый `synergy.html` включён в репозиторий, чтобы результат можно было посмотреть без запуска генератора.
