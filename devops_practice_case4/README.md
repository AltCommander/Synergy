
# Кейс-задача №4 — Игра "Угадай число" (Python)

**Задание:**  
- Случайно выбрать число в диапазоне (по умолчанию 1..100).  
- Принимать попытки пользователя, подсказывать "слишком маленькое/большое".  
- Ограничить количество попыток (по умолчанию 7).  
- Реализовать валидацию ввода и аккуратную обработку ошибок.  

## Запуск
Интерактивный режим по умолчанию:
```bash
python3 guess_number.py
```
Параметры (опционально):
```bash
python3 guess_number.py --attempts 10 --low 1 --high 100
```

## Пример
```text
$ python3 guess_number.py
Я загадал число от 1 до 100. У вас 7 попыток.
Попытка 1/7. Ваше число: 50
Слишком маленькое.
...
Поздравляю, вы угадали число 73 за 6 попыток!
```
