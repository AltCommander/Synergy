
# Кейс-задача №2 — Факториал (Python)

**Задание:** 
- Запросить у пользователя положительное целое число.  
- Вычислить факториал введённого числа.  
- Обработать ошибки (нечисловой ввод, отрицательные значения, ноль).  
- Оптимизировать вычисления с помощью `math.factorial`.

## Как запустить
```bash
python3 factorial_calculator.py
# интерактивный режим
# Введите число по запросу
```
Или в неблокирующем режиме:
```bash
python3 factorial_calculator.py 25
```

Для очень больших `n` программа выведет только количество цифр результата, чтобы не засорять консоль.

## Тесты (pytest)
Установите pytest (опционально) и запустите:
```bash
pip install pytest
pytest -q
```

## Пример
```text
$ python3 factorial_calculator.py
Введите положительное целое число: 6
6! = 720
Цифр в результате: 3
```
